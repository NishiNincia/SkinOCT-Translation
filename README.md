
## Cross-Modal Skin Imaging: Dermoscopy-to-OCT-Like Image Synthesis

A deep learning project exploring cross-modal medical image translation using **CycleGAN and PyTorch**. The project investigates the generation of synthetic OCT-like images from dermoscopic skin images through unpaired image-to-image translation.

The implementation uses two generators and two discriminators with adversarial, cycle-consistency, and identity losses, along with an experimental structural regularisation component.

**Key Technologies:** Python · PyTorch · CycleGAN · CNN · Medical Image Processing

**Original Kaggle Notebook:** [View Project on Kaggle](https://www.kaggle.com/code/nishinincia/skinoct-ml/)

*Note: The generated OCT-like images are synthetic outputs for research experimentation and are not clinical OCT scans or intended for medical diagnosis.*
